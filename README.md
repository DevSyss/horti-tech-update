# Sistema de Gerenciamento de Câmaras Frias

Sistema desenvolvido como projeto acadêmico de **Desenvolvimento Full Stack**, integrando **Frontend, Backend, Banco de Dados, IoT e documentação técnica**.

O projeto tem como objetivo desenvolver uma solução para **gerenciamento e monitoramento de câmaras frias**, permitindo o controle das informações do sistema e a integração entre software, banco de dados e dispositivos IoT.

O desenvolvimento foi realizado como projeto integrador das disciplinas do **3º/4º Semestre do Curso de Desenvolvimento de Sistemas** do **SENAI Gaspar Ricardo Junior — CFP 402 — Sorocaba/SP**.

**Professor Instrutor:** [Vedilson Prado](https://github.com/vedilsonprado)

## Arquitetura do Projeto

O sistema foi estruturado utilizando uma arquitetura Full Stack, dividida em diferentes camadas:

```text
                    SISTEMA DE CÂMARAS FRIAS
                              |
          +-------------------+-------------------+
          |                   |                   |
       Frontend            Backend               IoT
          |                   |                   |
   HTML / CSS / JS       Java / Spring       Sensores /
                              |              Dispositivos
                              |
                           MySQL
                         Banco de Dados
```

---

## Funcionalidades

Entre as principais funcionalidades planejadas para o sistema estão:

* Gerenciamento das câmaras frias;
* Cadastro e consulta de informações;
* Monitoramento das condições das câmaras;
* Integração com dispositivos IoT;
* Armazenamento das informações em banco de dados;
* Comunicação entre Frontend e Backend;
* Controle e visualização das informações do sistema;
* Interface web para gerenciamento da aplicação.

## Objetivo do Projeto

O projeto busca aplicar, de forma integrada, os conhecimentos adquiridos durante o curso de **Desenvolvimento de Sistemas**, unindo desenvolvimento web, programação backend, banco de dados e tecnologias IoT em uma única solução.

A proposta é desenvolver um sistema capaz de auxiliar no **monitoramento e gerenciamento de câmaras frias**, centralizando informações e facilitando o acompanhamento das condições do ambiente.
