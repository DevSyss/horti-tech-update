Perguntas frequentes

Respostas rápidas para as tarefas mais comuns
Como cadastrar uma câmara fria?

Acesse Câmaras frias, selecione Novo registro, preencha a identificação e os limites térmicos e salve. O cadastro será enviado à API configurada.

Por que o gráfico não mostra dados?

O gráfico utiliza leituras recebidas da API. Confira se o Spring Boot e o MySQL estão ativos, se existem registros térmicos e se a rota configurada em script/config.js corresponde ao controller.

O cadastro ou login apresentou erro?

Confira o e-mail, os campos obrigatórios e a mensagem exibida. Se o erro persistir, verifique a rota de autenticação e as regras de validação do backend.

Os dados não carregam?

Verifique se o backend está rodando em http://localhost:8080, se o endpoint existe e se o CORS permite a origem do front-end.

Fale com o suporte

Descreva o problema. O botão prepara uma mensagem no seu aplicativo de e-mail.

Este formulário não grava chamados no banco. Para isso, o backend precisa ter uma entidade e um endpoint de suporte.
